서랍을 하나 더 만들고 싶어요

잠금 화면 아래 「서랍 추가」를 누르고, 지금 쓰는 서랍 번호를 먼저 넣으세요(폰을 잠깐 든 사람이 서랍을 만들지 못하게 하려는 거예요). 그다음 이름·색을 고르고 새 번호를 두 번 넣으면, 그 서랍의 복구 키가 나와요. 서랍 안 설정 › 「서랍 추가」로도 만들 수 있어요.

번호를 잊었어요

잠금 화면에서 「번호를 잊었어요」를 누르세요.

  • 복구 키: 그 서랍을 만들 때 받은 28자 키로 열고, 바로 새 번호를 정해요.
  • Face ID / Touch ID: 그 서랍에 켜 뒀다면 계속 열 수 있어요. 번호를 새로 정하려면 복구 키가 필요해요.

번호와 복구 키를 모두 잃으면 누구도, 저희도 열 수 없어요. Tuck은 번호를 어디에도 저장하지 않기 때문이에요.

사진 앱의 원본은요?

사진 앱에서 가져온 사진은 서랍 사본이 제대로 열리는지 확인한 뒤에만 원본을 삭제하거나 가려요. 서랍 설정 「사진 앱 원본」에서 매번 묻기·삭제·가리기·남겨 두기를 고를 수 있어요.

  • 삭제한 원본은 사진 앱 「최근 삭제된 항목」에서 최대 30일 안에 되살릴 수 있어요.
  • 가린 원본은 사진 앱의 「가려진 항목」 앨범에서 「가리기 해제」를 누르면 다시 보여요. 가려진 사진은 다른 앱이 볼 수 없어서 Tuck이 대신 되돌릴 수 없어요.

앱을 지우거나 아이폰을 바꾸면요?

서랍 안의 사진·문서는 이 아이폰 안에만 암호화되어 있어요. 이 버전에는 iCloud 백업이 없어서, 앱을 지우면(다시 깔아도) 서랍도 함께 지워지고 아이폰 백업으로 옮겨지지도 않아요. 지우거나 바꾸기 전에 서랍마다 설정 › 「모두 내보내기」로 사본을 사진·파일 앱에 저장하세요.

Adding a drawer

On the lock screen tap “One more drawer” and first enter the PIN of a drawer you already use (so nobody holding your phone can add drawers). Then pick a name and colour, enter the new PIN twice, and note that drawer’s recovery key. You can also use Settings › One more drawer inside a drawer.

I forgot my PIN

On the lock screen tap “Forgot PIN?”. Use that drawer’s 28-character recovery key to open it and set a new PIN right away. If Face ID / Touch ID is on for that drawer you can keep opening it, but setting a new PIN needs the recovery key. Without the PIN and the recovery key nobody can open the drawer — not even us.

Originals in Photos

Tuck deletes or hides an original only after checking that the copy in your drawer opens. Deleted originals stay in Photos › Recently Deleted for up to 30 days. Hidden originals: open the Hidden album in Photos and tap Unhide (Tuck can’t see hidden photos, so it can’t undo this for you).

Deleting the app or changing iPhones

Everything in your drawers lives encrypted on this iPhone only. This version has no iCloud backup, so deleting the app (even to reinstall it) deletes your drawers, and an iPhone backup doesn’t carry them over. First use Settings › Export everything in each drawer.

Ajouter un tiroir : sur l’écran verrouillé, touchez « Un tiroir de plus » et saisissez d’abord le code d’un tiroir existant. Choisissez ensuite un nom et une couleur, saisissez deux fois le nouveau code et notez la clé de secours de ce tiroir.

Code oublié ? Sur l’écran verrouillé, touchez « Code oublié ? », ouvrez le tiroir avec sa clé de secours et choisissez tout de suite un nouveau code. Avec Face ID / Touch ID vous pouvez continuer à l’ouvrir, mais un nouveau code demande la clé. Sans le code ni la clé, personne ne peut ouvrir le tiroir — pas même nous.

Supprimer l’app ou changer d’iPhone : cette version n’a pas de sauvegarde iCloud. Supprimer l’app (même pour la réinstaller) efface les tiroirs, et une sauvegarde de l’iPhone ne les transfère pas. Utilisez d’abord Réglages › « Tout exporter » dans chaque tiroir.
